Inline SVG rather than an image file, for the same reason as icon.html - one fewer request, and it inherits size from the caller. The seal red is `seal-600`, which exists only for brand furniture; it is never a status colour and, per docs/BRAND.md section 5, a seal must never be stamped next to register data, where it would read as "certified by us". The character is set as SVG text in a system CJK serif. If a reader has no such face installed they still see the seal, which is the recognisable half.
