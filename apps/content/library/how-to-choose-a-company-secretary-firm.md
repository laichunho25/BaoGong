市面上提供公司秘书服务的机构很多，报价从几百到几千港元都有。**在比价之前，先把不该进入比较范围的排除掉。**

## 第一关：牌照（不通过就不用往下看）

在香港，**以业务形式为他人提供信托或公司服务——包括担任公司秘书、提供注册地址——必须持有 TCSP 牌照**，由公司注册处发牌，法律依据是《打击洗钱及恐怖分子资金筹集条例》（第 615 章）。无牌经营属违法。

要核对两件事，不是一件：

1. **对方是否在持牌名单上**——名单公开可查
2. **牌照是否仍然有效**——牌照有期限，会到期，也可能不再续期

**注意用词。** 「我们有营业执照」「我们是注册会计师行」「我们已经做了十几年」——这些都不等于持有 TCSP 牌照。请直接索取**持牌人姓名／机构名称与牌照号码**，再自行到公司注册处的公开名单核对；本平台也每日同步官方名单，并显示每家的牌照状态与最后同步时间。

一家已经不在名单上的机构仍然可以营业、可以收费。但它替你保管的法定记录、替你递交的申报，都建立在一个已经失效的资格上。

## 第二关：收费透明度

低价常常来自**把项目拆出去**。请把报价还原成一张清单，逐项确认「包不包」：

| 项目 | 包含？ |
|---|---|
| 公司秘书年费 | |
| 注册地址 | |
| 信件扫描转发（频率？） | |
| 周年申报表递交（**政府注册费另计？**） | |
| 董事／股东／地址变更申报（每次另收？） | |
| 法定记录册备存与更新 | |
| 重要控制人登记册（SCR）维护 | |
| 商业登记证续期代办（**政府费用另计**） | |
| 做账、审计、报税 | |
| 银行开户陪同或文件准备 | |

两条经验：

- **政府收费和服务费要分开看。** 商业登记费、周年申报注册费是交给政府的，不同服务商代收的金额应该一样；差异出在服务费上。
- **问清第二年的价格。** 首年优惠、次年跳价是常见做法，比较时请用**三年总成本**。

至于合理区间：市场上的年费差距很大，取决于包含哪些项目。**本平台按服务项目列出各家的价格区间，请以平台上的实际数据对照，不要用单一一家的报价当成市场行情。**

## 第三关：回应速度与交接条款

这两项在合同期内比价格更影响体验：

- **回应速度**：试着在委托之前发一封询问邮件，看多久回、答得具体不具体。**成交前的回应速度，通常已经是上限。**
- **谁是对接人**：有没有固定联系人？换人怎么通知？
- **信件处理**：紧急文件（税务局、法院）是否即时通知？
- **退出条款**：想换服务商时，法定记录册如何移交、地址变更由谁申报、有没有额外的「离场费」。**这一条要在进场时就看清楚。**

## 三个值得停下来想一想的信号

1. **不问任何问题就接单。** 持牌机构本身受反洗钱制度约束，须对客户做尽职审查。**向你索取护照、住址证明和业务说明是它的法定义务**；完全不问的那一家，问题不在服务好，在合规。
2. **报价明显低于市场且不肯拆项。** 价格本身不是问题，说不清楚包含什么才是。
3. **对开户结果作出承诺。** 开户与否由银行决定，任何人都无法保证结果。听到这类说法，请对其他承诺也保持同样的怀疑。

## 委任之前的最后三个问题

- 我们公司的成立周年日是哪一天？
- 下一次周年申报由谁递交，什么时候提醒我？
- 如果因你方原因逾期，费用由谁承担？（写进合同）
